# Título

Este projeto consiste num artefacto digital interativo desenvolvido em p5.js que explora a geometria sagrada e o desenho generativo através de uma mandala paramétrica em constante mutação. O artefacto gera camadas concêntricas de pétalas que ondulam organicamente no tempo.
O artefacto cruza três ingredientes fundamentais onde a posição do rato atua como input interativo para controlar em tempo real a densidade das pétalas e a amplitude da forma. A expressão visual foi conseguida através de funções trigonométricas e coordenadas polares moduladas pelo tempo (frameCount), criando um efeito visual rico e dinâmico a partir de poucas linhas de código. O resultado culmina num output de forte impacto estético e visual.
O desenvolvimento do código foi acompanhado e testado localmente no VSCode, integrando os conceitos de matemática aplicada ao design e repetição modular.
O recurso a ferramentas de inteligência artificial cingiu-se estritamente a uma ajuda de suporte técnico para afinar a equação trigonométrica das ondas concêntricas e o mapeamento suave das cores. Todo o código gerado foi testado e iterado por mim, ajustando manualmente os parâmetros.
